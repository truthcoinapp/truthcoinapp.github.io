# truthcoinapp.github.io

The organisation's root page: a short page linking to the [Truthcoin App](https://github.com/truthcoinapp/truthcoin-app)
and its phone page, and the app's icons at the root of the domain (`/apple-touch-icon.png`, `/favicon.ico`), where some
browsers look for them instead of reading the page's own links. The icons come from truthcoin-app (MIT).
